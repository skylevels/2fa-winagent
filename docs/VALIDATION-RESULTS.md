# Результаты проверки реализации

Основные проверки выполнены 5 ноября 2026 года в Linux-среде с PHP CLI 8.4.23 и PowerShell 7.4.13; дополнения установщика проверены 10 ноября. Развёртывание на Windows/DC и выпуск настоящих сертификатов AD CS не выполнялись.

- PHP: 129 проверок, без ошибок. Покрыты сроки, продления, очистка, отзыв пары, исключения, отмена таймеров при локальном выключении, очереди/пакеты, IP/HMAC, повторы, отсутствие административных HTTP-маршрутов, локальные команды, журналирование, TLS и преобразование PFX в PEM. Отдельные 21 проверка покрывают support endpoints/capability, предел 60 секунд, разделение режимов, общие sequence, запоздалые ответы, исключения, очистку и поздние отзывы после выключения.
- `tests/durations.php`: 13 проверок настраиваемых сроков. Подтверждены границы Config 30–600/30–180, default 300/60, только целые значения, независимые сроки pair/support, очистка на границе, ограничение абсолютного expires_at, сохранение дедлайна при задержках/переводе часов, отсутствие продления при повторе и подписанные целочисленные поля статуса.
- `tests/revoke_retry.php`: 14 регрессионных сценариев. Проверены pair/support, временная ошибка и подтверждённая внутренняя очистка, одинаковый повтор через 601 секунду, повторная ошибка, сохранение более новой выдачи, изменение GUID/fingerprint/endpoint, ограничения выключенного режима/массового обхода, заполненный кэш и запрет повторной неудавшейся выдачи. Используется имитация AD, реальных доменных команд нет.
- `tests/powershell/Directory.Tests.ps1`: 40 проверок с подменёнными командами AD, без ошибок; включены support-clear/deny, подтверждение записи чтением, исключения защищённых групп и отказ при неопределённом членстве.
- `tests/powershell/Maintain-Logs.Tests.ps1`: 14 проверок с настоящими временными файлами и ZIP, включая сбои/проверку архива/повтор/срок хранения, без ошибок.
- `tests/powershell/Distribution.Tests.ps1`: 10 проверок состава, контрольной суммы, повторной сборки, неполного исходника, исключения секретов/TLS, владельца каталогов и дополнительных документов, без ошибок. PHP в этих проверках — файловая фикстура, не запущенный Windows-интерпретатор; ACL/владельцы проверены на подменённых дескрипторах.
- `tests/powershell/LocalAdmin.Tests.ps1`: 12 проверок протокола, подписей, ограничений, потерянной квитанции, повторов и монотонных сроков, без ошибок. Проверка настоящей Windows ACL именованного канала пропущена в Linux.
- `tests/powershell/Certificate.Tests.ps1`: 5 проверок INF/SAN/шаблона, срока и PEM, без ошибок. Реального обращения к CA не было.
- `tests/powershell/Install-Port.Tests.ps1`: 5 проверок нового порта 8443, свободного/занятого слушателя, независимости от службы на 443, строгого целочисленного значения и JSON Int64. Сетевые команды подменены; настоящие службы и Firewall не изменялись.
- `tests/powershell/Install-Secret.Tests.ps1`: 9 проверок генерации ключа, сохранения IP/прочих настроек, приватных прав до записи, проверки настоящим PHP Config, атомарной замены и отказа повторной установки, без ошибок. NTFS-права в этих сценариях подменены; настоящие права проверяются отдельно на Windows.
- `tests/powershell/Install-Online.Tests.ps1`: 16 проверок, без ошибок. Покрыты разрешённые HTTPS-адреса, SHA-256 и закреплённая ревизия GitHub, распаковка/обход путей/коллизии/фактические размеры, проверка издателя Microsoft, коды VC++ и конечное ожидание процесса, PHP/OpenSSL, настройка IP/8443, запасной URL PHP только при 404, перенаправления и общий срок загрузки. Сеть, Authenticode, VC++, NTFS и AD CS в тестах заменены; настоящие установщики не запускались. Повторены 10 проверок дистрибутива и 9 проверок создания секрета.
- Проверка происхождения: собственных скомпилированных программ и встроенного компилятора нет. ZIP исходников не содержит нативных бинарников; 66 PE-файлов PHP полного комплекта совпадают с официальным PHP ZIP, VC++ EXE — с проверенным входным файлом Microsoft.
- `tests/powershell/Install-Acl.Tests.ps1`: сценарии для NTFS подготовлены; запускать в повышенной консоли Windows. В Linux не выполнялись.
- Синтаксис PHP и PowerShell проверен. Совместимость Windows PowerShell 5.1 требует запуска на целевой ОС.
- Настоящий дочерний процесс: передача JSON, защита конфигурации, ошибки, таймаут, завершение и восстановление проверены через тестовый исполняемый файл.
- Настоящий HTTPS-слушатель и независимый Python TLS/HMAC-клиент: доверие тестовому сертификату и DNS-имя, подписи ответов, три API-маршрута, 404 для административных маршрутов, отказ ключу admin и отсутствие открытого HTTP проверены на временном локальном порту. AD в этом сценарии заменён тестовым обработчиком.
- Дополнительно проверены настоящие IPv4/IPv6 HTTPS-соединения: источник отклоняется до TLS, число подключений ограничено, зависшие TLS/заголовки/тело закрываются, большое chunked-тело получает немедленный 413, корректный запрос сохраняет подпись и может выполнять AD-обработчик дольше срока приёма. При закрытии зависшего TLS event loop продолжает работу. Воспроизведение: `python3 tests/https_ingress.py --php /path/to/php`; нужны Python 3 и OpenSSL CLI, используются только временные файлы и loopback.
- `composer validate`: конфигурация действительна. Предупреждение об отсутствующем поле лицензии проекта сохранено: лицензия распространения пользователем не выбиралась.
- Повторный сетевой `composer audit --locked` 5 ноября 2026 не обнаружил опубликованных предупреждений и заброшенных пакетов; версии PHP-библиотек не менялись. Полный комплект содержит официальный Windows PHP 8.4.27-1; Linux-интерпретатор 8.4.23 применялся только для локальных проверок.

Проверки не подтверждают работу настоящего Active Directory, Kerberos, RDP, разблокировки Windows, репликации между DC, Task Scheduler/Firewall/NTFS, named-pipe ACL, AD CS или поведение антивируса. Для этого предусмотрен [план проверки Windows](WINDOWS-VALIDATION.md). Код портала в этой проверке не изменялся; его трёхсекундный таймаут и политика каскада рассмотрены в [отчёте безопасности](SECURITY-REVIEW.md).
