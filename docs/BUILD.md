# Сборка из исходников

Агент состоит из PHP и PowerShell. Собственного EXE/DLL и скрытого компилятора нет.
В Git хранятся исходники, `composer.lock`, открытые сборочные скрипты и контрольные
суммы загрузок. Для автоматического установщика опубликованы также
`dist/windows-agent.zip` с текстовыми PHP-зависимостями и его `.sha256`.
Каталоги `vendor/`, `.build/` и полный архив с Windows PHP/VC++ в Git не входят.

`deploy/Install-AgentOnline.ps1` скачивает исходный ZIP и контрольную сумму из
одного коммита GitHub, проверяет закреплённый SHA-256 официального PHP и подпись
Microsoft у актуального VC++ Runtime. Сборка полного офлайн-комплекта ниже
использует зафиксированные входные файлы из `download-inputs.json`.

Для сборки на отдельной Windows-машине нужны PowerShell 5.1+, Python 3.10+ и
Microsoft Visual C++ Runtime x64. Права администратора не нужны сборщику; установка
системного runtime при его отсутствии выполняется отдельно. Не собирайте поверх
работающего агента или его конфигурации.

Из каталога `windows-agent`:

```powershell
.\deploy\Prepare-Distribution.ps1
python .\deploy\Build-Distribution.py --build
```

Подготовка загружает только HTTPS-компоненты из `deploy/download-inputs.json`,
сверяет SHA-256, а у Microsoft runtime — также действительную Authenticode-подпись.
Официальный PHP распаковывается во временный рабочий каталог; через него
выполняется Composer `install --no-dev --prefer-dist --no-plugins --no-scripts`
по зафиксированному `composer.lock`. Исходное дерево и установленный агент не
изменяются. Имеющийся каталог зависимостей не перезаписывается.

Контрольные суммы: PHP 8.4.27-1 NTS VS17 x64 — из официальных метаданных PHP;
Composer 2.11.1 — из официального файла `composer.phar.sha256sum`.
SHA Microsoft runtime фиксирует проверенную загрузку; HTTPS-ссылка Microsoft
может со временем выдавать новую версию. При изменении байтов подготовка
откажет в сборке: новую версию и её подпись нужно проверить и отдельно обновить
зафиксированные URL/хеши. Не отключайте проверку хеша.

Результат в `dist/`:

- `windows-agent.zip` — только текстовые исходники и PHP-библиотеки;
- `windows-agent-all-in-one.zip` — исходники, официальный Windows PHP и VC++ runtime;
- рядом с каждым архивом — `.sha256`.

Сборщик не загружает и не запускает программы, только упаковывает заранее
проверенные входы. Каждый выходной файл сверяется после записи ZIP; полный пакет
содержит происхождение компонентов и пофайловый `sources/manifest.sha256`.
Временные метки ZIP фиксированы; при необходимости задайте `SOURCE_DATE_EPOCH`.
Одинаковый набор входов и версия Python/zlib дают повторяемые архивы.

Параметры позволяют использовать отдельный проверенный кэш, в том числе на Linux:

```bash
python3 windows-agent/deploy/Build-Distribution.py \
  --inputs-dir /path/to/verified-inputs \
  --vendor-dir /path/to/locked-vendor \
  --output-dir /path/to/build-output --build
```

Без `--build` выполняется только проверка входов. В каталоге inputs должны быть
PHP ZIP и VC++ EXE с точными именами из `download-inputs.json`. Пакеты vendor
проверяются по версиям и исходным commit из `composer.lock`; файлы исходной части
должны быть UTF-8. Секреты, рабочие JSON-настройки, сертификаты, ключи, БД,
журналы, ссылки, reparse points и обход путей не экспортируются. Входной PHP ZIP
имеет ограничения числа/размера файлов и степени сжатия.

Linux-сборка подтверждает хеши, но сама не проверяет Windows Authenticode.
Перед запуском включённого Microsoft EXE на Windows проверьте его подпись по
инструкции `START-HERE.txt`. Сборка не означает проверку настоящих AD, NTFS,
Windows/RDP-входа и репликации; эти испытания выполняются отдельно.
